# Session Start Checklist

Use this checklist at the beginning of each new coding session.

## 1) Ingest wiki context

Read these files in order:

1. `wiki/index.md`
2. `wiki/current-state.md`
3. `wiki/architecture-map.md`
4. `wiki/recent-changes.md`
5. `wiki/open-issues.md`
6. `wiki/deploy-and-ops.md`
7. `wiki/log.md`

## 2) Return startup summary

Provide:

- 8-12 bullets for current mental model
- Top 5 active risks/todos
- Most recent meaningful changes
- Recommended next 3 actions

## 3) Maintain wiki during work

- Update relevant wiki pages whenever behavior/code/process changes.
- Append a dated entry to `wiki/log.md` for notable work.
- Keep entries concise and cross-linked.
- Do not paste large command outputs into wiki pages.
